# X2 Mobile plugins for Claude Code

A public Claude Code plugin marketplace from X2 Mobile.

## Add the marketplace

In Claude Code:

```
/plugin marketplace add X2Mobile/x2-plugins
```

## Plugins

| Plugin | What it does | Install |
|---|---|---|
| [motorika](plugins/motorika) | Fast, reliable Chrome control for AI agents over MCP: tabs, forms, clicks, video frames, headed or headless. Source: [X2Mobile/motorika-mcp](https://github.com/X2Mobile/motorika-mcp). | `/plugin install motorika@x2mobile` |

Updates: `/plugin marketplace update x2mobile`.
